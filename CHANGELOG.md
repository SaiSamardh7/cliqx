# Changelog

Notable changes to Cliqx. The version lives in [`VERSION`](VERSION) and nowhere
else; `tools/check-version.py` fails CI when a build configuration drifts from
it.

This project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — unreleased

First release candidate. Not yet submitted to the App Store; see
[`docs/ROADMAP.md`](docs/ROADMAP.md) for what is still open.

### Added

- Watch Clean opens directly from an episode card, and a poster with no picture
  in it is refused rather than rendered blank.
- Server episodes resume from the home screen, and are remembered on the device
  that holds them.
- Declared API usage and reviewer notes for App Store submission.

### Changed

- One interruption rule replaces the previous overlapping set, and the `Fill`
  mode now actually fills.
- Version unified at 1.0.0 across all four build configurations — two had
  carried 0.1, so which version shipped depended on which scheme was built.

### Fixed

- Hijacked loads are no longer followed, and players the agent had been missing
  are now found.
- Rule counts in the app and the docs are generated from the shipped manifest,
  so they cannot drift from the rules that actually ship.
- Test counts are checked by `tools/count-tests.py --check` in CI, after being
  wrong for two weeks.

## [0.8.0] — 2026-09

### Added

- Strict blocking level restored as a real superset of Standard: 183,732 rules
  against 134,166, guarded by two tests.
- Fanboy's Annoyance shipped as a fourth compiled list (49,566 rules). EasyList
  Cookie was deliberately not added — Fanboy's already contains the Cookie and
  Social lists.
- Jellyfin server client, and playback of local files from Files.
- App icon, generated by `tools/make-icon.py` rather than checked in as a
  binary, with `tools/check-icon.py` guarding both ways it breaks.

### Changed

- Brave's 944 compatibility exceptions are folded into the same `FilterSet` as
  the rules they undo. WebKit applies `ignore-previous-rules` only within its own
  compiled list, so the previous design — a separate unbreak list — cancelled
  nothing at all.
- A card, a title and a stream now stay bound to the page they came from.
- Native is the single authority on what "same site" means and hands the agent a
  registrable domain.

### Fixed

- The home screen reads **Cliqx**; it installed as "CleanPlayerApp" until
  `INFOPLIST_KEY_CFBundleDisplayName` was set.
- The audio group: volume control no longer touches system volume at all.
- CI runs once per commit. `push` and `pull_request` previously both fired for a
  branch with a PR open and two macOS matrices fought over the same runners.
