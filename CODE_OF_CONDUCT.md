# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help. Argue about the code, not
about the person who wrote it.

## The standard

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Examples of behaviour that contributes to a good environment:

- Giving and accepting constructive feedback gracefully
- Taking responsibility for mistakes, and learning from them
- Focusing on what is best for the project rather than for being right

Unacceptable behaviour includes harassment, personal or political attacks,
publishing others' private information, trolling, and sexualised language or
imagery.

## Scope

This applies in the issue tracker, pull requests, discussions, and anywhere
someone is representing the project.

## Enforcement

Report a problem privately to the maintainer,
[@SaiSamardh7](https://github.com/SaiSamardh7), through GitHub. Reports are
handled confidentially.

This is a one-maintainer project. Enforcement is proportionate and, in practice,
means a warning, then a block. Decisions are not appealable to a committee that
does not exist.
